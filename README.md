# 🌐 WebStudio

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=github)](https://artemishchenkogit.github.io/web-studio/)
[![Source Code](https://img.shields.io/badge/Source-Code-blue?style=for-the-badge&logo=github)](https://github.com/artemishchenkoGIT/web-studio)

A modern, responsive landing page for a web development studio. The website is built to present business solutions, highlight core services, display team members and portfolio projects, and provide a user-friendly contact interface for potential clients.

## ✨ Features & Functionality

- **Responsive & Adaptive Layout:** Perfectly displays across desktop, tablet, and mobile screen resolutions.
- **Hero & Services Section:** Clear call-to-action (CTA) with modal window trigger for client service requests.
- **Team & Portfolio Showcase:** Interactive elements presenting agency members and completed business projects.
- **Interactive Modal Form:** Functional contact form for project inquiries and client applications.
- **Cross-Browser Compatibility:** Smooth rendering across all major modern web browsers (Chrome, Edge, Firefox, Safari).

## 🛠️ Tech Stack & Tools

- **Markup & Styling:** HTML5, CSS3

## 🚀 Getting Started Locally

To run and build this project locally, make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/artemishchenkoGIT/web-studio.git
```

### 2. Navigate to the project directory
```bash
cd web-studio
```

### 3. Install dependencies
```bash
npm install
```

---

## 📜 Available Scripts

In the project directory, you can run the following commands:

### 🛠️ Development Mode
Runs the application in development mode with a local server and live-reloading:
```bash
npm run dev
```

### 📦 Production Build
Builds the app for production to the output folder (`dist` or `build`). It optimizes assets for performance and produces production-ready bundles:
```bash
npm run build
```
